# SalesSetu — Frontend Application

Next.js 15 App Router frontend application for the **SalesSetu** AI Sales Operating System.

## Stack
- **Framework:** Next.js 15 (React 19)
- **Styling:** Tailwind CSS + Radix UI + Lucide Icons
- **State Management:** Zustand + TanStack React Query
- **Charts & Motion:** Recharts + Framer Motion
- **Drag & Drop:** `@dnd-kit`

## Features
- **Dashboard:** AI Daily Brief, Today's Meetings, Hot Leads, At-Risk Deals
- **AI Sales Agent:** Autonomous prospecting and execution copilot
- **ICP Builder:** Natural language ideal customer profile builder
- **Lead Discovery:** Multi-filter company & contact search with intent scoring
- **Companies & POCs:** 360° company views, executive research dossiers
- **Outreach & Approval Inbox:** Multi-touch email & LinkedIn drafts with human-in-the-loop approvals
- **Meetings & MoM:** Automatic minutes of meeting generation, action items, sentiment scoring
- **Deal Pipeline:** Kanban board with deal health, probability, and stage management
- **Analytics & Calendar:** Conversion funnels, rep performance, schedule management

## Setup Instructions

1. Install dependencies (already prepared):
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
